== 0.2.5 ==
* Detalii recepție și listă produse recepționate.
* Documente atașate recepției prin WordPress Media Library.
* Tipuri: Factură furnizor, Aviz, Certificat garanție, Document transport, Fișă tehnică și Alt document.
* Metadate: număr, dată, titlu, note, MIME și dimensiune.
* Fișiere permise: PDF, JPG, PNG și WebP.
* Arhivare logică; fișierul nu este șters din Media Library.
* Trasabilitate document → recepție → comandă → furnizor.

Faceți backup și instalați mai întâi în staging.
